Tahap berikutnya: Database online

Kita akan memakai Supabase untuk menyimpan bank soal secara online. Bagian ini adalah panduan persiapan; aplikasi belum tersambung sampai proyek database dibuat dan konfigurasi aman dipasang.

1. Buat proyek

Buka supabase.com, daftar, lalu buat proyek baru bernama RuangTKA.

2. Siapkan tabel

Di menu SQL Editor, jalankan SQL contoh di bawah untuk membuat tabel bank soal.

3. Hubungkan aplikasi

Setelah tabel dan aturan akses siap, barulah aplikasi dapat membaca dan menyimpan soal ke database online.

SQL awal untuk tabel bank soal

create table public.questions (
  id bigint generated by default as identity primary key,
  subject text not null,
  question text not null,
  options jsonb not null,
  correct_answer integer not null check (correct_answer between 0 and 4),
  explanation text not null,
  created_at timestamptz not null default now()
);

alter table public.questions enable row level security;

-- Aturan akses perlu ditambahkan sebelum aplikasi digunakan.
-- Jangan aktifkan akses tulis publik untuk bank soal.
Penting: SQL ini hanya membuat struktur tabel dan mengaktifkan keamanan baris. Belum ada kebijakan akses, koneksi aplikasi, login, atau penyimpanan nilai siswa. Jangan masukkan secret/service_role key ke halaman website.
